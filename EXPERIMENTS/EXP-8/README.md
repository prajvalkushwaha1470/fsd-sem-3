
# Experiment 8: MongoDB Student Database

## Objective
Perform CRUD operations on the studentDB database.

## Operations Performed

1. Insert 5 student records using insertMany().
2. Find students older than 20 using $gt.
3. Update a student's age using $set.
4. Delete one student using deleteOne().
5. Display all remaining student records.

## Database
- Database: studentDB
- Collection: students

## Technology Used
- MongoDB
- MongoDB Atlas
- VS Code
- MongoDB for VS Code Extension
